# Marks

アプリ内で使う印とワードマーク。どれも単色で、`<img>` で表示するため色は固定してある。

- `mark.svg` — 印だけ (地は透過)。塗りは `roast` の Paper の値 `#4a2f1c`。ログイン画面 (72 px)、記録が無いときの表示 (56 px、不透明度 0.6)、ナビゲーションレールの上 (40 px) に使う。
- `mark-night.svg` — 同じ印を Night の `roast` (`#dbb890`) で塗った版。ダークテーマではこちらに切り替える。
- `wordmark.svg` — 「brewbook」を IBM Plex Serif 500 でパスにしたもの。塗りは `#4a2f1c`。フォントを読み込めない場所 (メール、README、OGP 画像) で使う。アプリ内では `wordmark` のテキストスタイルで組む。
- `wordmark-night.svg` — 同じく `#dbb890` の版。

印を色や形で作り変えない。印とワードマークを横に並べるときは、印の高さをワードマークの 1.6 倍にし、間を `space-3` 空ける。

# Stats

統計。期間を選び、抽出と購入の集計をグラフで見る (FR-18)。

- AppBar は最上位の形 (ハンバーガーメニュー、印、「統計」)。
- 上部に期間の `Chip` (当月、3 か月、6 か月、12 か月、全期間、任意)。既定は当月の日別。その下に選択中の範囲と粒度を `caption` で 1 行 (「2026-09-01 から 2026-09-26 まで、日別」)。
- 任意を選ぶと開始日と終了日の `Field` と「適用」が現れ、62 日以下は日別、それ以外は月別と注記する。終了日が開始日より前なら `validationPeriod`。
- 合計のタイル (抽出回数、豆の消費量) の下に、抽出回数、豆の消費量、購入金額 (通貨ごと)、購入重量 (通貨ごと)、抽出条件と評価の散布図 4 つの順で `Charts` を並べる。
- 読み込みは 3 経路を順に呼び、届いた順に描く。期間を切り替えたら古い応答を捨てる。
- 広い画面ではグラフを 2 列に並べる。

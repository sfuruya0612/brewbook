# Settings

パスキーの管理、エクスポート、アカウントの削除、ログアウトを 1 画面に置く (FR-3、FR-14、FR-15)。

- AppBar は最上位の形 (ハンバーガーメニュー、印、「設定」)。
- セクションは `heading` の題と `body` の説明 (ARB の `*Description`)、操作の順で、`line` の罫線で区切る。
- パスキー: 行ごとに鍵の印、名前、登録日時と最終使用日時 (`mono`)、名前の変更と削除のアイコン。1 つしか無いときは削除を `ink-faint` で無効化し、押しても 409 の文言を出す。「パスキーを追加」は次点ボタン。
- エクスポート: 次点ボタン「エクスポートをダウンロード」。完了はスナックバー。
- アカウントの削除: `signal` の枠の「アカウントを削除」。押すと確認ダイアログ (`Feedback`) を出し、「削除する」を押したときだけ API を呼ぶ。削除後はログイン画面へ。
- ログアウト: 末尾に文字ボタン。ドロワーの末尾にも置く。

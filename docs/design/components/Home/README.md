# Home

抽出の一覧。アプリを開いて最初に見る画面で、「抽出を記録」の FAB がここから 1 画面で保存まで進む (PRD の成功指標)。

- AppBar は最上位の形 (ハンバーガーメニュー、印、画面名「抽出」)。ハンバーガーで開くドロワーに抽出、購入、商品、店、統計、設定と、区切りの下にログアウトを置く (issue 0015 と 0016 の配線をドロワーに移す)。
- 上部に「アーカイブ済みを含める」の切り替え (`toolbar`)。オンにするとアーカイブ済みの行が混ざり、バッジで区別する。
- 行は `ListRow` の抽出の形。抽出日時の降順。
- 記録が無いときは `mark.svg` を薄く置き、「記録がありません」と「右下の「抽出を記録」から最初の 1 杯を記録します。」。
- 起動時の確認に失敗したとき (ネットワーク、500) はバナーと「再試行」を中央に出す。

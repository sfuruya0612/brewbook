# Charts

fl_chart で描く統計のグラフ。色は `chart-count` (件数と金額。`roast`) と `chart-grams` (グラム。`crema`) の 2 つだけ。

- 棒グラフ: 抽出回数と豆の消費量、購入金額と購入重量。系列ごとに別のグラフにし、1 つの軸に単位の違う系列を混ぜない。通貨はグラフを分けて題に「(JPY)」と付け、色で分けない (FR-18)。
- 軸は `line-strong` の 1 px、目盛は `line` の横罫 2 本 (最大と半分)。目盛の数字とラベルは `mono` の 11 px、`ink-muted`。日別は先頭、中央、末尾の 3 つだけラベルを出す。
- 記録の無い区間は棒を描かない。集計が空のときはグラフの代わりに「記録がありません」を `empty` の形で出す。
- 散布図: 抽出条件と評価の 4 つ (豆の量、湯量、湯の温度、時間)。点は `chart-grams` の 3.5 px、不透明度 0.85。縦軸は 1 から 5。条件が null の抽出は描かない。2 列に並べる。
- 折れ線: 購入の詳細の評価の推移。線は `chart-grams` の 2 px、点は `paper-raised` の塗りに `chart-grams` の 2 px の輪。横軸は最初と最後の日付だけ。
- 題は `heading`、右端に単位 (「杯 / 日」「g / 月」) を `mono` の `caption` で。グラフの下に `line` の罫線を引いて次と区切る。
- 期間の合計 (抽出回数、豆の消費量) はグラフの上に `value-large` のタイル 2 つで示す。

# Chip

高さ 32 px の丸い (`radius-full`) 小さな選択肢。統計の期間の単一選択と、フレーバーノートのタグに使う。

- 期間 (当月、3 か月、6 か月、12 か月、全期間、任意) は `line-strong` の枠で並べ、選択中だけ `roast` の塗りと `on-roast` の文字。常に 1 つを選択中にする。
- タグは `crema-soft` の地に `ink` の文字、右に 14 px の削除アイコン。末尾に破線の「タグを入力」を置いて追加する。
- 一覧と詳細の中では高さ 22 から 24 px、文字 12 px に縮めて表示だけにする (削除アイコンを付けない)。
- 文字は `label` (13 px の 500)。折り返さず、収まらないときは行を折り返してチップを増やす。
- Dioxus では `frontend/src/ui/chip.rs` で `.chip` のクラスを組む (選択中は `.on`、タグは `.tag`、追加は `.add`、一覧と詳細の中は `.mini`)。

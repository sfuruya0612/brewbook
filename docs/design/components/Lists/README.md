# Lists

購入、商品、店の一覧。ホームと同じ `ListRow` と切り替えと FAB で組み、種類ごとに 2 行目と右端だけ変える。

- AppBar は最上位の形 (ハンバーガーメニュー、印、種類名)。ドロワーから開く最上位の画面で、ホームの上に積まない (ドロワーの項目を切り替える)。
- FAB の文言は「購入を記録」「商品を登録」「店を登録」。
- 購入: 写真、商品名、購入日と店、重量と価格。購入日の降順。
- 商品: 商品名、生産地と精製方法と品種、タグ。名前の昇順。
- 店: 店名と住所。名前の昇順。
- どの一覧も 50 件ずつ追加で読む。アーカイブ済みは切り替えで含める。

# Lists

購入、商品、店の一覧。ホームと同じ `ListRow` と切り替えと FAB で組み、種類ごとに 2 行目と右端だけ変える。

- AppBar はハンバーガーメニューと「brewbook」、その下に種類名 (購入、商品、店) と戻る。ハンバーガーメニューから開き、ホームの上に積む。
- 一覧の上にツールバーを置く (0051)。並び順の選択、昇順/降順の切り替え、お気に入りのみの切り替え。既定は購入日 (購入)、登録日 (商品、店) の降順で、お気に入りの絞り込みなし。
  - 購入: 購入日、価格、重量。
  - 商品: 登録日、商品名、更新日。
  - 店: 登録日、店名、更新日。
- 行の右端に星を置き、押すとお気に入りを付け外しする (FR-21)。行の押下 (詳細や編集を開く) は発火しない。
- FAB の文言は「購入を記録」「商品を登録」「店を登録」。
- 購入: 写真、商品名、購入日と店、重量と価格。
- 商品: 商品名、生産地と精製方法と品種、タグ。
- 店: 店名と住所。
- どの一覧も 50 件ずつ追加で読む。

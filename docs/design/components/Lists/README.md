# Lists

購入、店の一覧。ホームと同じ `ListRow` と切り替えと FAB で組み、種類ごとに 2 行目と右端だけ変える。

- AppBar は最上位の形 (ハンバーガーメニュー、印、種類名)。ドロワーから開く最上位の画面で、ホームの上に積まない (ドロワーの項目を切り替える)。
- FAB の文言は「購入を記録」「店を登録」。
- 購入: 写真、商品名、購入日と店、重量と価格。購入日の降順。行の星の左に「この購入をもとに登録」を置き、押すとその購入の商品の項目と店と焙煎度を引き継いだ登録のフォームを開く (幅 840 px 以上では右の面に出す。issue 0058)。
- 店: 店名と住所。名前の昇順。
- どの一覧も 50 件ずつ追加で読む。アーカイブ済みは切り替えで含める。

# Detail

抽出の詳細と購入の詳細。`Ledger` の表と `ReferenceTile` の連鎖で組む。

- 抽出の詳細: 題は商品名 (`title`)、その下に抽出日時 (`mono`、`ink-muted`) と `Rating`。表は豆の量、湯量、湯の温度、時間、抽出方法、挽き目、評価。感想の段落。「使った豆」の見出しの下に購入、商品、店のタイル (店が無ければ省く)。AppBar の右端はアーカイブと編集。
- 購入の詳細: 左に 112 px の写真 (無ければカメラの印)、右に商品名、店、タグ。表は購入日、焙煎度、焙煎日、価格、重量、写真 (差し替え / 削除)。その下に「評価の推移」の折れ線 (`Charts`)。商品と店のタイル。
- アーカイブを押すとその場で状態を反映し、題の横にバッジを出してスナックバー「アーカイブしました。」。解除も同じ場所から。
- 写真の差し替えと削除は表の行の文字ボタンから。アップロード中は行の文字を「アップロード中」にして無効化する。失敗は「再試行」付きのバナー。

# Detail

抽出の詳細と購入の詳細。`Ledger` の表と `ReferenceTile` の連鎖で組む。

- 抽出の詳細: 題は商品名 (`title`)、その下に抽出日時 (`mono`、`ink-muted`) と `Rating`。表は豆の量、湯量、湯の温度、時間、抽出方法、挽き目、評価。感想の段落。「使った豆」の見出しの下に購入、店のタイル (店が無ければ省く)。AppBar の右端はお気に入り、編集、削除。
- 購入の詳細: 左に 112 px の写真 (無ければカメラの印)、右に商品名、店、タグ。表は生産者、生産国、地域、精製方法、品種、購入日、焙煎度、焙煎日、価格、重量、写真 (差し替え / 削除)。その下に「AI による味と特徴」の節。豆の情報から推定したまとめ、Flavor Notes のタグ、酸味、甘み、苦味、ボディ、香り、精製方法の説明、地域の特色、おすすめの淹れ方、おすすめの挽き目の表を出し、AI の推定である旨の注記を添える。保存済みの推定は画面を開いたときに表示し、無いときは「AI に聞く」を押したときだけ推定する。推定中は待機の表示、失敗は再試行のバナーにする。推定し直すと保存済みの推定を上書きする。その下に「評価の推移」の折れ線 (`Charts`)。店のタイル (店が無ければ省く)。AppBar の右端はお気に入り、この購入をもとに登録 (`content_copy`)、編集、削除。「この購入をもとに登録」は商品の項目と店と焙煎度を引き継いだ登録のフォームを開く (幅 840 px 以上では右の面に出す。issue 0058)。
- 写真の差し替えと削除は表の行の文字ボタンから。アップロード中は行の文字を「アップロード中」にして無効化する。失敗は「再試行」付きのバナー。

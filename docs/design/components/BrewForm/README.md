# BrewForm

抽出の記録と編集。購入と抽出日時以外は任意で、1 画面に収める (FR-11)。

- 上から: 購入のピッカー (必須)、抽出日時 (日付と時刻の 2 欄、既定は現在時刻)、豆の量と湯量、湯の温度と時間 (2 列の数値欄、単位付き)、抽出方法 (サジェスト)、挽き目 (サジェスト)、評価 (`Rating` の大)、感想 (複数行)。
- 保存は AppBar の右端の文字ボタン。先頭は閉じる。保存に成功したらホームへ戻ってスナックバー「保存しました。」。
- 検証エラーは画面の上にバナー、項目には枠と理由。購入が未選択なら ピッカーの枠を `signal` にして「購入を選んでください。」。
- 数値は小数第 1 位まで (豆の量、湯量、湯の温度)、時間は整数の秒。範囲外は `validationDecimal` と `validationNumber` の文言。
- 編集は同じ画面で題を「抽出を編集」にし、値を入れた状態で開く。抽出日時は端末のローカル時刻で表示する。

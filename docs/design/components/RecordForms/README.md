# RecordForms

購入の記録と商品の登録 (店の登録は店名と住所の 2 欄で同じ形)。

- 購入: 商品のピッカー (必須)、店のピッカー (任意。「店を指定しない」)、購入日 (既定は当日)、焙煎度 (サジェスト)、焙煎日、価格と通貨 (2 対 1 の 2 列。通貨の既定は JPY)、重量 (g)、写真。
- 写真は 88 px の枠と「写真を選ぶ」、その下に変換の注記 (「JPEG に変換し、長辺 2048 px 以下に縮小して保存します。」)。選んだら枠に表示し、ボタンを「写真を差し替え」と「写真を削除」の 2 つにする。
- 商品: 商品名 (必須)、生産者、生産国と地域 (2 列)、精製方法と品種 (2 列)、フレーバーノート (`Chip` のタグ入力)。自由記述の 5 項目は全てサジェスト付き。
- 店: 店名 (必須)、住所。
- 保存とエラーの扱いは `BrewForm` と同じ。

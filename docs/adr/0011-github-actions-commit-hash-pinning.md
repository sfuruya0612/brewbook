# ADR-0011: GitHub Actions の action をコミットハッシュで固定する

Created: 2026-09-26
Model: DeepSeek V4.1 Flash
Status: Accepted

## 背景

`.github/workflows/ci.yml` は `actions/checkout@v7.0.1` と `jdx/mise-action@v4.3.0` をタグで固定している。
Git のタグは書き換え可能で、同じタグが別のコミットを指すようになると、CI はそのまま別のコードを実行する。

ADR-0009 はツールの版を `mise.toml` で固定する方針を定めたが、GitHub Actions の action の固定方法は定めていない。
所有者が 2026-09-26 に、action の版をコミットハッシュで固定することを決めた。

## 決定

- ワークフローの `uses` は、タグではなく検証したコミットの SHA (40 桁) で固定する。
  どのバージョンかが分かるように、バージョンをコメントに残す。
- 2026-09-26 時点の値は次の通り (同日に GitHub の API で、タグの指すコミットを確認した)。

| action | タグ | コミット |
| --- | --- | --- |
| actions/checkout | v7.0.1 | 3d3c42e5aac5ba805825da76410c181273ba90b1 |
| jdx/mise-action | v4.3.0 | c2a87611a18de5b3828c5652fe268e992400cb5c |

- 更新は所有者が手動で行う。
  手順は、GitHub のリリースとタグを確認し、タグの指すコミットを GitHub の API または `git ls-remote` で取得し、ワークフローとバージョンのコメントを書き換えて、CI の通過を確認する、とする。
  更新の確認日をコメントに残す。
- 変更は issue 0024 で行う。
  あわせて `.github/workflows/ci.yml` のコメント「action の版はタグで固定する (ADR-0009)」を、本 ADR を参照する形に直す。
  ADR-0009 は action の固定方法を定めたものではない。
- Dependabot や Renovate などの自動更新は導入しない。
  検証を通した変更だけをマージする方針 (PRD の制約と前提) と、依存と設定を増やさない方針 (ADR-0001) による。

## 検討した選択肢

| 選択肢 | 採用しない理由 |
| --- | --- |
| タグのまま固定する | タグの書き換えで、検証していないコードが CI で実行される余地が残る |
| メジャーバージョンのタグ (v7 など) で固定する | タグの書き換えの問題に加え、後方互換でない変更が自動で入る |
| Dependabot や Renovate で自動更新する | action の更新を自動化できるが、設定と外部サービスへの依存が増える。所有者が手動更新を選んだ |
| コミットハッシュと Dependabot を併用する | 上と同じ理由。加えて、自動更新の pull request の検証が CI の通過だけでは足りない (action の内容を人が確認しない) |

## 結果

- CI は、確認したコミットの action だけを実行する。
- action の更新は手動になり、更新のたびにバージョンコメントと CI の通過を確認する。
- 本 ADR は action の更新の時期を定めない。
  必要なときに所有者が更新する。

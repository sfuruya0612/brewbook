# ADR-0018: アーカイブ (論理削除) を廃止する

Created: 2026-10-03
Model: DeepSeek V4.1 Flash
Status: Accepted

## 背景

ADR-0006 は、店、商品、購入、抽出の 4 つの記録の削除を論理削除 (アーカイブ) と決めた。
アーカイブは `archived_at` 列 (NULL なら有効) で表し、既定の一覧は `archived_at IS NULL` で絞り、アーカイブとアーカイブ解除の API と画面を持つ。

2026-10-03 に所有者は、アーカイブ機能を不要と決めた。
既存のアーカイブ済みの記録は削除せず、通常の記録として扱う。

## 決定

- アーカイブ (論理削除) の概念を画面、API、データベースから削除する。
- 店、商品、購入、抽出の 4 テーブルから `archived_at` 列を削除する。
- 一覧と統計の複合インデックスを、`archived_at` を含まない形に作り直す。
  最終スキーマのインデックスは `idx_shops_user_created_at`、`idx_products_user_created_at`、`idx_purchases_user_purchased_on`、`idx_brews_user_brewed_at` の 4 つで、いずれも (利用者 ID、並び順のキーの降順、ID) を張る。
- 一覧、単件取得、統計、サジェスト、エクスポートのクエリから `archived_at` の条件と列を消し、アーカイブ無しの前提に揃える。
- アーカイブとアーカイブ解除の 8 経路 (店、商品、購入、抽出の各 2 経路) を削除する。
- アーカイブ済みの参照先を 409 で拒否する規則を削除し、存在しないか他の利用者のものだけを 404 にする。
- 一覧の `include_archived` パラメータを削除する。
  指定されたリクエストは未知のパラメータとして無視する。
- アーカイブ済みだった行は削除しない。
  マイグレーションは `DELETE` を書かず、列とインデックスだけを変更する。
- ADR-0006 を部分置き換えにする。
  ADR-0006 の Status を「Partially superseded by ADR-0018 (2026-10-03)」に変え、本文の冒頭に置き換えの注記を足す (同じ変更で行う)。
  データモデルの他の決定は残す。
- PRD の用語、目的、ユースケース、スコープ、エラー応答、FR-5、FR-9、FR-11、FR-12、FR-13、FR-14、FR-18、FR-19、関連資料と、`docs/design/` のアーカイブの記述を本 ADR に合わせて改訂する。
- 新しい API と権限は追加しない。

## 検討した選択肢

| 選択肢 | 採用しない理由 |
| --- | --- |
| `archived_at` 列を残して画面と API だけ削除する | 使われない列とインデックスが残り、スキーマと ADR-0006 が実装と食い違う (所有者の回答で却下) |
| アーカイブ済みの記録をマイグレーションで物理削除する | 所有者の回答は「記録は残す」である |
| アーカイブを物理削除の機能に置き換える | 所有者の要望は削除機能の追加ではなくアーカイブの削除であり、新しい削除の API と画面は要求に無い |
| FR-12 の番号を詰める | FR-12 を参照する記述が本文の複数箇所にあり、参照の付け替えを誤る危険が大きい (欠番を残す) |
| ADR-0006 の Status を「Superseded」にして本文を書き換える | データモデルの他の決定 (4 つの記録の関係、物理削除はアカウント削除だけ) は有効なままなので部分置き換えにする。本体の書き換えは履歴を消すため却下する |

## 結果

- マイグレーション `backend/brew_book/migrations/0003_remove_archive.sql` が、列を参照する 4 つのインデックスを `DROP INDEX` し、4 テーブルの `archived_at` を `ALTER TABLE ... DROP COLUMN` で削除し、`archived_at` を外した 4 つのインデックスを作る。
  D1 に適用済みの既存の行は残る。
- 一覧、単件取得、更新の応答から `archived_at` が消える。
- アーカイブ済みだった記録は通常の記録として一覧、統計、サジェスト、エクスポートに含まれる。
- スキーマの検証は、0001、0002、0003 を順に適用した最終スキーマ (4 テーブルに `archived_at` が無いこと、4 つのインデックスが `archived_at` を含まないこと) を対象にする。
  ADR-0006 との列の照合は、本 ADR が定める最終スキーマとの照合に置き換える。
- 本番の D1 への 0003 の適用は、デプロイの issue で行う。
